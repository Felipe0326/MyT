VERSIÓN 4.9.3 — AJUSTES VISUALES SOLICITADOS

Cambios realizados únicamente:
1. Favicon nuevo basado en el emblema de Morelos, optimizado para pestañas pequeñas.
2. Pantalla de carga: se sustituyeron las letras “MT” por el logotipo institucional y se conservó el texto “Protegiendo tu acceso…”.
3. Login: se agregaron iconos dentro de los campos de correo y contraseña; se conserva el botón para mostrar u ocultar la contraseña.
4. Filtros de NPS y Refrendos: se sustituyeron los desplegables que presentaban saltos por menús estables, con apertura/cierre suave y aplicación del filtro después de cerrar el menú.

No se modificaron:
- SQL ni funciones de Supabase.
- Flujos de n8n.
- Lógica de autenticación.
- Consultas, gráficas, tablas o filtros disponibles.
- Diseño general de los tableros.

IMPORTANTE:
El archivo .env.local no se incluye para no copiar credenciales. Conserva el .env.local de tu proyecto actual en la raíz, junto a package.json.

Para ejecutar:
  npm install
  npm run dev

Después recarga el navegador con Ctrl + F5. Si el favicon anterior sigue visible, cierra esa pestaña y abre localhost nuevamente, porque Chrome suele guardar el favicon en caché.
