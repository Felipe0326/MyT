# Cambios V4.8 · Correo automático

- SMTP institucional configurable mediante secretos.
- Resend se conserva como respaldo opcional.
- Invitación automática con el mismo botón de creación.
- Reenvío automático con token nuevo e invalidación del enlace anterior.
- Recuperación de contraseña desde la pantalla de acceso.
- Enlaces de recuperación de 60 minutos, uso único y almacenamiento SHA-256.
- Revocación de sesiones después de cambiar la contraseña.
- Respuesta neutra para evitar revelar qué correos están registrados.
- Enlace manual de invitación conservado mientras TI completa el SMTP.
- Documentación y migración SQL específicas para la V4.8.
- Next.js actualizado a 16.2.12 y Nodemailer fijado en 9.0.3.
