SISTEMA MOVILIDAD Y TRANSPORTE - ENTREGA FINAL PARA VERCEL
===========================================================

Esta versión usa Next.js de forma nativa en Vercel.
No utiliza Nitro para el despliegue y no genera la carpeta .output.
El build genera la carpeta .next que Vercel espera.

1. EJECUCIÓN LOCAL
------------------
Abra PowerShell dentro de la carpeta sistema-movilidad-tym y ejecute:

  npm install
  npm run dev

Dirección local:
  http://localhost:3000

El archivo .env.local se conserva dentro del proyecto.

2. CONFIGURACIÓN DE VERCEL
--------------------------
El archivo vercel.json ya configura:
  Framework: Next.js
  Install Command: npm install
  Build Command: npm run build
  Output Directory: .next

Si el proyecto anterior de Vercel conserva configuraciones manuales de Nitro,
Vite, Other o .output, elimine esos Overrides o cree un proyecto nuevo usando
esta carpeta.

Root Directory:
- Déjelo vacío si package.json está en la raíz del repositorio.
- Use sistema-movilidad-tym si esa carpeta está dentro de otra carpeta del repositorio.

3. VARIABLES DE ENTORNO EN VERCEL
---------------------------------
Agregue en Settings > Environment Variables:

  SUPABASE_URL
  SUPABASE_ANON_KEY
  SUPABASE_SERVICE_ROLE_KEY
  RATE_LIMIT_SECRET

Variables de correo cuando infraestructura las entregue:
  SMTP_HOST
  SMTP_PORT
  SMTP_SECURE
  SMTP_USER
  SMTP_PASSWORD
  SMTP_FROM

APP_URL NO ES OBLIGATORIA PARA EL PRIMER DESPLIEGUE.
El código detecta automáticamente el dominio de Vercel o el origen de la petición.
Cuando exista un dominio institucional definitivo, APP_URL puede configurarse con:
  https://dominio-oficial.morelos.gob.mx

4. DESPLIEGUE
-------------
Suba la carpeta al repositorio y haga Deploy o Redeploy sin usar la caché anterior.

IMPORTANTE:
- .env.local permanece en la carpeta local.
- .vercelignore evita que .env.local se envíe al despliegue.
- Las claves reales deben configurarse en Vercel Environment Variables.
- No use Output Directory .output ni Framework Nitro para esta versión.
